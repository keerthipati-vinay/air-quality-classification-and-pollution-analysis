About the Project

Air Quality Classification & Pollution Analysis is an AI-powered web application developed using FastAPI, PostgreSQL, HTML, CSS, JavaScript and Machine Learning. It predicts Air Quality Index categories, stores prediction history, provides interactive dashboards, and includes secure role-based authentication for Users and Administrators.
